# Interactive Quiz Assessment System

A responsive **web-based quiz application** built with **HTML, CSS, and JavaScript**. It provides an interactive quiz experience with randomized questions, difficulty-based miss limits, real-time score tracking, and detailed performance review.

## Features

* 30-question question bank
* Random selection of 10 questions
* Easy, Medium, and Hard difficulty levels
* Real-time score and miss tracking
* Automatic pass/fail evaluation
* Interactive multiple-choice interface
* Detailed answer review
* Try Again functionality
* Responsive and clean UI

## Tech Stack

* **HTML5** — Page structure and quiz screens
* **CSS3** — Responsive layout, Flexbox, Grid, CSS variables, and UI styling
* **JavaScript** — Quiz logic, randomization, state management, event handling, and DOM manipulation

## Quiz Flow

```text
Select Difficulty
       ↓
Randomize Questions
       ↓
Select 10 Questions
       ↓
Answer Questions
       ↓
Track Score & Misses
       ↓
View Result
       ↓
Review Performance
```

## Difficulty Levels

| Level  | Maximum Misses |
| ------ | -------------: |
| Easy   |              7 |
| Medium |              5 |
| Hard   |              3 |

A score of **5/10 or higher** is required to pass while staying within the selected miss limit.
